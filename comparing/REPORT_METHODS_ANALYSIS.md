## 大原則 (2026-05-29 ユーザ合意)
- **手法はテーマ非依存**。EO/DME/スチレン/MEK… どのテーマのレポートでも、やっている最適化手法
  (変数を1つずつ掃引・粗いグリッド・後置ピンチ 等) は PDH sim の変数に写して再現できる。
- テーマが効くのは **そのレポートの報告最適値と数値比較する時だけ** (PDH 同士なら直接突合できるおまけ)。
- だから「PDH 限定」ではなく、**いろいろなテーマのレポートを分析して**手法を再現する。
- 信頼するのは各 md の **「📖 最適化セクション原文」** のみ。🎯変数表/🔁テンプレは正規表現の残骸で無視。

## 横断的所見 (= 手法の本質)
1. **手法は数種類しかない**: ①1次元逐次 (C01。PDH2025a/PDH2024a/PDH2025b/EO)、②粗いグリッド (C02。ProPro 3×3 / トルエン 80点)、
   ③短絡計算 (C03 FUG。トルエン)、④後置ピンチ (C04。ほぼ全件)。テーマが変わっても手法は同型。
2. **変数集合だけが違う**: 反応器転化率 (PDH2024a/ProPro/トルエン)、塔の圧力・段数・温度 (PDH2025a/PDH2025b/EO)、
   パージ率/O2比/吸収塔温度 (EO/トルエン)。→ 各レポート = 「どの変数を・どの順/グリッドで」動かしたかの違い。
3. **sim に写せない変数**: パージ率 (P03。sim が未露出→要 flowsheet 改造)、O2比/吸収塔温度 (PDH に該当装置なし)。
   これらは「構造 (座標降下/グリッド) は写すが、その変数は PDH の最寄り変数に置換 or 省略」と明記して再現。
4. **PDH 6 本は報告最適値とも数値突合できる** (同テーマ)。他テーマは手法 (=欠陥) の再現と BO比 ΔTAC のみ。

## 既に sim へ写した手法部品 (caseN=PN、shared 流用)
- 1次元逐次 = case_p04_sequential / 各レポート版 (case_rep_pdh2025a, case_rep_pdh2024a)
- 粗いグリッド = case_p05_grid / case_rep_propro2019 / case_rep_toluene2023
- 後置ピンチ = case_p02_pinch / 典型フルワークフロー = case_combo_typical
- 部分最適化 = case_p01_subsystem / multi-start(大域性) = case_p06_multistart / 収束未検証 = case_p12_converge

## 今後 (テーマをさらに足す時の手順)
1. レポート md の 📖 原文だけ読み、「最適化因子・順序/グリッド・刻み・報告最適」を抜く。

4. 実走行は HYSYS のある PC で (このマシンでは import/構文確認まで)。
