Aspen HYSYS 蒸留塔（Column）カスタマイズ & オートメーション包括ガイド
本ガイドは、Aspen HYSYS V7.1における蒸留塔（Column）オブジェクトの操作、設計、およびオートメーションに関する技術仕様をまとめた専門エンジニア向けのリファレンスである。シミュレーションの精度と計算速度を最適化するため、エンジニアは以下に詳述するオブジェクト階層とプログラミング手法を厳格に遵守しなければならない。
--------------------------------------------------------------------------------
1. 蒸留塔オブジェクトの基本構造とアクセス
Aspen HYSYSにおける蒸留塔は、単一のユニットオペレーションでありながら、内部に独自のフローシートを保持する特殊な階層構造を持つ。
1.1 ColumnOp と ColumnFlowsheet の定義
ColumnOp: メインフローシート（Main Flowsheet）上に配置された、プロセスユニットとしての蒸留塔オブジェクト。
ColumnFlowsheet: 蒸留塔の内部詳細（サブフローシート）を保持する。各ステージの物理的詳細、圧力プロファイル、および収束のための仕様設定（Specifications）はこのオブジェクトを介してのみ管理される。
1.2 オブジェクト階層の解説
特定の蒸留塔にアクセスするためには、以下の階層構造を順に辿る必要がある。
SimulationCase: 最上位オブジェクト。
Flowsheet: メインフローシート。
Operations: ユニットオペレーション・コレクション。
ColumnOp: 蒸留塔本体。
ColumnFlowsheet: 内部サブフローシート。
1.3 ProgID とアーリーバインディングの厳守
外部プログラム（Excel VBA等）から接続する場合、適切な ProgID を使用してインスタンスを作成する必要がある。また、実行速度の向上とインテリセンスの活用のため、汎用的な Object 型ではなくタイプライブラリで定義された型を使用する**アーリーバインディング（早期結合）**を常に選択すべきである。
ProgID
説明
HYSYS.Application.Latest
登録されている最新バージョンのHYSYSを起動する。
HYSYS.Application.2006
HYSYS 2006 (V7.1等) を明示的に起動する。
HYSYS.SimulationCase
最後に登録されたバージョンのシミュレーションケースを起動する。
--------------------------------------------------------------------------------
2. カラム仕様（ColumnSpecification）による運用管理
蒸留塔の収束計算を正しく制御するためには、Specifications コレクションの適切な管理が不可欠である。
2.1 仕様オブジェクトの操作
仕様設定は、ColumnFlowsheet.Specifications を介して管理される。各仕様が計算の制約条件となっているか、単なる見積値（初期値）であるかは、IsActive プロパティによって決定される。
IsActive = True: 仕様は「アクティブ」であり、収束計算の制約条件（Constraint）として機能する。
IsActive = False: 仕様は「見積値（Estimate）」であり、初期値としてのみ利用される。
2.2 主要プロパティ一覧
仕様の管理に使用すべき主要プロパティを以下に示す。
プロパティ
説明
GoalValue
仕様の目標値。設定時は内部SI単位系（SI units）が適用される。
CurrentValue
現在の計算値（読み取り専用）。
IsActive
仕様が制約条件として有効かを示す（Boolean）。
--------------------------------------------------------------------------------
3. ステージレベルの流体プロパティ操作
物理構造としての「器（うつわ）」と、その内部の「流体」は別個のオブジェクトとして定義されている。
3.1 オブジェクトの役割分担
ColumnStage: 物理的なトレイや位置を表すトポロジー上のコンテナ。
SeparationStage: ColumnStage の配下に位置し、そのステージにおける流体の物理的性質（流量、組成、結果データ）を保持する。
3.2 データ取得の実装例
特定のトレイからモル液流量（MolarLiquidFlowValue）を取得する場合のコード記述。 molarFlow = objColumnSubFlow.ColumnStages.Item(0).SeparationStage.MolarLiquidFlowValue
3.3 FeedStages による効率的なループ処理
供給が存在するステージのみを処理する場合、FeedStages コレクションから得られる名前（name）をキーとして、ColumnStages インデックスへ戻すロジックを構築する必要がある。
FeedStages コレクションをループ処理する。
hyFeedStage.name を取得し、それを ColumnStages の引数として渡す。
SeparationStage にアクセスし、StageNumberValue などのプロパティを抽出する。
--------------------------------------------------------------------------------
4. ストリーム接続の特定と固定アタッチメント
蒸留塔に接続されている外部ストリームや論理操作を特定するには、FixedAttachments コレクションを使用する。
4.1 接続情報の抽出
ColumnOp に接続されている要素は、以下の4つのコレクションに分類される。
AttachedFeeds: フィードストリーム（ProcessStream）。
AttachedProducts: 製品ストリーム（ProcessStream）。
AttachedLogicalOps: 論理演算オブジェクト（UnitOperation）。
AttachedOpers: その他接続されているユニット（UnitOperation）。
これらに対し Item プロパティでアクセスし、name プロパティを取得することで接続情報を特定できる。
--------------------------------------------------------------------------------
5. 配列を用いた大規模データの取得
全ステージの情報を取得する際は、通信オーバーヘッドを抑えるため配列（Variant型）での一括取得が推奨される。
5.1 圧力プロファイル（1次元配列）
Pressures プロパティを用いて全ステージの圧力を取得する。
hyStagePressure = objColumnSubFlow.Pressures
UBound 関数で要素数を特定し、ループ処理を行う。
5.2 蒸気成分比率（2次元配列）
VapourComponentFraction プロパティは2次元配列を返す。
第1次元（成分）: インデックスは 0-based であり、FluidPackage.Components コレクション内の順序と厳密に一致する。
第2次元（ステージ）: インデックスは全ステージを網羅する。
例: hyCompFrac(0, 5) は「成分リストの1番目の成分」における「第6ステージ」の分率を指す。
--------------------------------------------------------------------------------
6. UI設計と Extension View Editor
6.1 エディタによるカスタマイズ
Extension Definition File (EDF) を用い、カスタムインターフェースを設計する。Extension View Editorを使用して、カラムの変数や計算結果を視覚的に配置する。
6.2 削除ターゲットと動的設定
仕様の削除ターゲット: カスタムUI上で仕様を削除する場合、EDF内で対象となる仕様のターゲットオブジェクトを適切に指定しなければならない。
動的ラベルとワークシート: ラベルには動的割り当てを行い、ワークシートの Wrap 設定には標準値 5 を使用することを原則とする。
--------------------------------------------------------------------------------
7. 設計上の重要な制約事項
蒸留塔（Column）のカスタマイズにおいては、標準的なユニットオペレーションとは異なる以下の制約を厳守しなければならない。
7.1 User Variables タブの制限
蒸留塔のプロパティビューには、標準的な User Variables（ユーザー変数）タブが存在しない。このため、カラムのデフォルトプロパティビューから直接ユーザー変数を管理することはできない。
7.2 代替設定環境とデータ型
ユーザー変数を定義・追加する場合は、必ず Basis Environment またはカラムのサブフローシート環境で行うこと。
選択可能なデータ型: Double, Integer, String。
設計上の注意: シミュレーションの一貫性を保証するため、複雑な依存関係を避け、適切なコンテキストで定義を行う必要がある。
--------------------------------------------------------------------------------
8. カスタマイズ FAQ とトラブルシューティング
8.1 特定の仕様（GoalValue）の設定
特定の仕様値を変更するための VBA 実装例。名前によるアクセス（Item）を行う際は、文字列の完全一致が必要である。
' カラム仕様オブジェクトの取得と目標値の設定
Dim hyColumnSpec As ColumnSpecification
Set hyColumnSpec = objColumnSubFlow.Specifications.Item("Ethanol_Mass_Frac")

' GoalValueの設定（注：内部単位系である SI units が適用される）
hyColumnSpec.GoalValue = 0.98 
8.2 パフォーマンスの最適化
大量のデータを一括入力する際、処理速度を劇的に向上させるため、以下の手順を厳守すべきである。
SimulationCase.Solver.CanSolve を False に設定し、計算を一時停止させる。
全データの入力を行う。
SimulationCase.Solver.CanSolve を True に戻し、一括で再計算を走らせる。
8.3 エラー回避策
未収束時のプロパティアクセス: カラムが収束していない状態で CompressibilityValue や MolarHeatCapacityValue などの流体性質にアクセスすると、ランタイムエラーが発生しスクリプトが停止する恐れがある。必ず On Error トラップを実装し、収束状態を確認してからアクセスすること。
アクティブ状態の確認: 値の変更が反映されない場合は、対象の仕様の IsActive プロパティが True であるかを確認せよ。非アクティブな仕様（見積値）は計算結果を拘束しない。
Aspen HYSYS V7.1 蒸留塔（Column）カスタマイズ技術詳細レポート
本レポートは、Aspen HYSYS V7.1における蒸留塔（Column）オブジェクトの操作、UI設計、およびオートメーションに関する高度な技術仕様をまとめたものである。シニア・プロセス・エンジニアおよびオートメーション・エキスパートは、シミュレーションの堅牢性と計算速度を最適化するため、以下のオブジェクト階層とプログラミング手法を厳格に遵守しなければならない。
--------------------------------------------------------------------------------
1. ColumnStage および SeparationStage への詳細アクセス構文
蒸留塔は、メインフローシート上のユニットオペレーション（ColumnOp）でありながら、内部に独自のサブフローシート（ColumnFlowsheet）を保持する特殊な階層構造を持つ。パフォーマンスの最大化と開発効率（Intellisenseの活用）のため、Object型を用いた遅延結合（Late Binding）ではなく、タイプライブラリを参照した**アーリーバインディング（早期結合）**の利用が必須である。
オブジェクト階層とProgID
特定のステージの流体データにアクセスするための完全なパスは以下の通りである。 SimulationCase -> Flowsheet -> Operations -> ColumnOp -> ColumnFlowsheet -> ColumnStages -> ColumnStage -> SeparationStage
外部アプリケーションから接続する際は、HYSYS.Application.Latest または HYSYS.Application.2006 を使用して、意図したバージョンのインスタンスを確実に確保すること。
アクセス構文の実装例
Operations("ColumnOp") はフィルタリングされた「コレクション」を返すため、個別のオブジェクト操作には .Item(0) 等による特定が必要である。
' アーリーバインディングによる宣言
Dim hyApp As HYSYS.Application
Dim hyCase As SimulationCase
Dim hyColumn As ColumnOp
Dim hyColumnSubFlow As ColumnFlowsheet

Set hyApp = CreateObject("HYSYS.Application.Latest")
Set hyCase = hyApp.ActiveDocument
' ColumnOpコレクションから特定の蒸留塔を取得
Set hyColumn = hyCase.Flowsheet.Operations("ColumnOp").Item("T-100")
Set hyColumnSubFlow = hyColumn.ColumnFlowsheet

' 1. インデックスによる指定 (0-based)
Dim molarFlow1 As Double
molarFlow1 = hyColumnSubFlow.ColumnStages.Item(0).SeparationStage.MolarLiquidFlowValue

' 2. 名前による指定 (String)
Dim molarFlow2 As Double
molarFlow2 = hyColumnSubFlow.ColumnStages.Item("1_Main TS").SeparationStage.MolarLiquidFlowValue
--------------------------------------------------------------------------------
2. FeedStages プロパティを用いた効率的なループ処理
全ステージを走査する手法は、大規模な蒸留塔においてOLE通信のオーバーヘッドを増大させる。供給（Feed）が存在するステージのみを特定して情報を取得することが、計算リソース最適化の観点から推奨される。
実装ロジック
FeedStages コレクションから得られる hyFeedStage.name をキーとして ColumnStages を参照し、StageNumberValue を取得する。
Dim hyFeedStage As Object ' FeedStagesコレクション用要素
Dim stageNum As Long
Dim liquidFlow As Double

With hyColumn.ColumnFlowsheet
    ' 収束状態の確認 (未収束時のアクセスによるランタイムエラー回避)
    If .IsConverged Then
        For Each hyFeedStage In .FeedStages
            ' 名前からステージ番号を特定
            stageNum = .ColumnStages(hyFeedStage.name).StageNumberValue
            ' 流体プロパティの抽出
            liquidFlow = .ColumnStages(hyFeedStage.name).SeparationStage.MolarLiquidFlowValue
            
            Debug.Print "Feed Stage: " & hyFeedStage.name & " (No. " & stageNum & ")"
        Next hyFeedStage
    End If
End With
--------------------------------------------------------------------------------
3. 大規模データ取得における 2D 配列（Variant）の活用
個別のステージごとにプロパティ（SeparationStage）へアクセスするのは、単一データの確認には適しているが、プロファイル全体を取得する際は非効率である。Variant 型の配列を用いて一括取得することで、通信回数を劇的に削減できる。
1次元配列: Pressures プロパティ等。
2次元配列: VapourComponentFraction プロパティ等。
第1次元 (Index 0): 成分 (Fluid Package 内の Components 順序に準拠)。
第2次元 (Index 1): ステージ (0 から全ステージ数まで)。
' 2次元配列による成分分率の一括取得例
Dim hyCompFrac As Variant
hyCompFrac = hyColumn.VapourComponentFraction

' 成分1、ステージ6 (Index 5) の分率を参照
Dim val As Double
val = hyCompFrac(0, 5)

4. FixedAttachments を用いた接続情報の列挙
蒸留塔に物理的に接続された境界ストリーム（フィード/プロダクト）を特定するには、ColumnOp オブジェクトの FixedAttachments コレクションを使用する。
Dim hyFeeds As FixedAttachments
Dim j As Integer

Set hyFeeds = hyColumn.AttachedFeeds
For j = 0 To hyFeeds.Count - 1
    ' 各フィードストリームの名称を取得
    Debug.Print "Attached Feed " & j & ": " & hyFeeds.Item(j).name
Next j

5. Extension View Editor における UI 設計と制約事項
カスタム UI（Extension View）を設計する際、蒸留塔特有の制約を理解しておく必要がある。
User Variables タブの制限（重要）
蒸留塔のデフォルト・プロパティビューには「User Variables」タブが存在しない。 これは一般的なユニットオペレーションとは異なる重要な制約である。ユーザー変数を追加・管理する場合は、必ず「Basis Environment」または「Column Sub-flowsheet」環境で行わなければならない。
UI 設計のベストプラクティス
削除ターゲット: ボタンウィジェットで仕様（Specifications）を削除する場合、EDF (Extension Definition File) 内でターゲットとなる仕様オブジェクトを厳密に定義する必要がある。
レイアウト: ワークシートの Wrap（折り返し）プロパティには、標準値 5 を使用することを原則とする。
動的ラベル: マトリックスウィジェットにおいて、実行時に取得した Specification Name を動的にラベルへ割り当てることで、構成変更に柔軟に対応する設計が求められる。

6. 特定成分の質量分率仕様を操作する VBA 実装
エタノール等の特定成分の質量分率（Mass Frac）仕様を変更する場合、以下のフローを遵守すること。特に大量の設定変更を行う際は、ソルバーの制御がパフォーマンスの鍵となる。
実装コード例
Dim hyColumnSpec As ColumnSpecification
On Error Resume Next ' エラーハンドリングの開始

' 仕様オブジェクトの取得 (名前は完全一致であること)
Set hyColumnSpec = hyColumnSubFlow.Specifications.Item("Ethanol_Mass_Frac")

If Not hyColumnSpec Is Nothing Then
    ' 計算制御の最適化：入力前にソルバーを一時停止
    hyCase.Solver.CanSolve = False
    
    ' 目標値の設定：内部単位系（SI units）が適用されるため注意
    hyColumnSpec.GoalValue = 0.98 ' 98 wt%
    
    ' 設定変更を確実に反映させるため IsActive を確認
    hyColumnSpec.IsActive = True
    
    ' 計算の再開
    hyCase.Solver.CanSolve = True
Else
    Debug.Print "Error: Specification not found."
End If
運用上の注意
単位系: GoalValue プロパティへの代入は常に SI 単位で行われる。単位換算が必要な場合は RealVariable.SetValue メソッドの利用を検討すること。
収束エラー: 未収束状態で CompressibilityValue 等の物理的性質にアクセスすると、ランタイムエラーが発生しスクリプトが停止する。必ず IsConverged プロパティの確認、または On Error トラップを実装し、シミュレーションの安定性を担保すること。
